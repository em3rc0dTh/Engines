## Classification vocabulary

Each important statement should be recognizable as one of:

- `SOURCE_FACT`
- `PROJECT_DECISION`
- `DESIGN_DECISION`
- `DESIGN_PROPOSAL`
- `DESIGN_REQUIREMENT`
- `UNKNOWN`

The purpose is to prevent a plausible idea from silently becoming project truth.
