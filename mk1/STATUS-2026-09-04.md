## Core architecture rule

**Engines comes first. CTA is independent and replaceable.**

```text
CLI ───────────┐
HTTP/API ──────┤
WebChat ───────┤
Telegram ──────┤── CTA boundary ── ENGINES
WhatsApp ──────┘
```

### Native-contact hardening observation

The second real-provider run exposed that the `Compartir teléfono` custom reply keyboard was not visibly presented in the operator's Telegram client. The typed-phone fallback remained valid and the registration completed, so provider E2E and validation recovery remain proven.

The renderer has now been hardened to request a persistent official ReplyKeyboardMarkup:

```text
request_contact = true
is_persistent = true
resize_keyboard = true
input_field_placeholder = set
```

The final C2P physical seal waits only for a fresh manual observation that the patched native `Compartir teléfono` control is visible and successfully produces a Telegram contact payload accepted by the same Engine path.
